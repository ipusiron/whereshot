WhereShot使用方法

            

                
🚀 基本的な使い方

                
    
                    
  1. 画像をアップロード: ドラッグ&ドロップまたはファイル選択
    2. 
                    
  2. メタデータ確認: Exif情報を自動抽出・表示
    3. 
                    
  3. 地図で位置確認: GPS情報があれば自動表示
    4. 
                    
  4. 太陽位置計算: 影の方向と照合して時刻を検証
    5. 
                    
  5. 外部データで詳細確認: 衛星画像や気象データと照合
    6. 
                


                
🔒 プライバシー保護

                
    
                    
  • すべての処理はブラウザー内で完結
    • 
                    
  • 画像・メタデータは外部送信されません
    • 
                    
  • 地図を表示すると、表示範囲のタイル番号が地図の配信元に送られる（画像とExifは送信しない）
    • 
                


                
UTCオフセット

                
解析日時は撮影地の現地時刻です。Exifのオフセット、GPS時刻との差、ブラウザーの順に候補を選びます。撮影地やカメラの時計に合わせて選び直してください。

                
⚠️ 注意事項

                
    
                    
  • GPS情報がない画像は手動で位置指定が必要
    • 
                    
  • 改ざんされた画像のメタデータは信頼できません
    • 
                    
  • 複数の情報源で検証することを推奨
    •
